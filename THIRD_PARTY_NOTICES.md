# Third-party assets and services

The MIT license in `LICENSE` covers this project's code and documentation. It does not grant rights to third-party names, logos or trademarks.

- `public/brand/ink-symbol.svg`, `public/brand/ink-symbol.png` and `public/brand/ink-wordmark.svg` use the Ink symbol and wordmark from the [official Ink brand kit](https://docs.inkonchain.com/work-with-ink/brand-kit). Ink and its marks belong to their respective owner and are not covered by this repository's MIT license. Do not present a fork as an official Ink product.
- The application catalogue uses names, categories and project links from the Ink directory, with summaries written for this explorer. Browsers request app logos from the original image URLs published by Ink. The respective owners retain rights to their names and logos. [Official Ink directory](https://inkonchain.com/apps) · [Catalogue sources and maintenance](docs/ARCHITECTURE.md#application-catalogue)
- Plus Jakarta Sans and DM Mono provide the interface and monospace text. Noto Sans Bengali and Noto Sans Devanagari provide Bengali and Devanagari glyphs. The four fonts ship through Fontsource under the SIL Open Font License 1.1. Include the relevant copyright and license notices when redistributing the font files. [Plus Jakarta Sans](public/licenses/plus-jakarta-sans-ofl-1.1.txt) · [DM Mono](public/licenses/dm-mono-ofl-1.1.txt) · [Noto Sans Bengali](public/licenses/noto-sans-bengali-ofl-1.1.txt) · [Noto Sans Devanagari](public/licenses/noto-sans-devanagari-ofl-1.1.txt)
- Wallet identicons are generated by [`blo`](https://github.com/bpierre/blo), which is MIT licensed. The pixel patterns are derived from addresses, not downloaded profile pictures.
- WalletConnect Ethereum Provider **2.21.8** and Reown AppKit **1.7.8** are Apache-2.0 licensed. Their license and notices ship in the installed packages; the built site includes [the Apache-2.0 license](public/licenses/walletconnect-apache-2.0.txt). Later SDK releases use different licenses and must not be substituted without review. Relay access requires the operator’s Reown project configuration.
- QR codes are generated locally with `qrcode.react` **4.2.0**, which is ISC licensed; no QR generation service receives pairing URIs. The built site includes [its license and copyright notice](public/licenses/qrcode-react-isc.txt).
- The explorer bundles selected token marks for identification. The provenance file records each source URL, local file and SHA-256 digest. Each mark belongs to its respective owner. [Token mark provenance](public/assets/marks/provenance.json)
- Blockscout, Contract Info, Ink RPC and NFT media are external data sources with their own terms. A running instance can fetch and cache additional token logos and NFT images on demand.

The Ink symbol identifies the covered chain. The explorer is independent and does not imply affiliation with Ink, Kraken or Blockscout. Replace the symbol when publishing a fork for another chain.

The dependency tree includes the MIT-licensed `@ryotsu/picomatch@4.0.7-a` fork of picomatch. Its npm archive contains the upstream copyright and license. The security policy records the exact revision and the additional upstream advisory check.
